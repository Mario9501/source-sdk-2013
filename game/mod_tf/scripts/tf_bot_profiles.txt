// TFBot overhaul: stock bot profiles (docs/tfbot/DESIGN.md, M1)

// Your own profiles go in tf_bot_profiles_custom.txt (same format, never
// overwritten); an entry there with the same name replaces one here.
//
// Entry kinds:
//   tier_*    skill tiers; tf_bot_difficulty 0..3 picks tier_new..tier_competitive
//   preset_*  reusable style building blocks, pulled in with "presets"
//   anything else is a named profile: a bot with that name uses it
//
// Keys and ranges: run tf_bot_profile_keys in the console. Values outside a
// key's range are clamped with a warning. "base" inherits from another entry;
// "presets" applies a comma list of presets on top. Bots without a named
// profile get their tier's values with a small per-name variation, and their
// style traits and class preferences are derived from their name.
//
// Skill values are a starting point from published human data (visual reaction
// around 200-250 ms for experienced FPS players) and are meant to be tuned by
// playtesting (design doc 3.2).
